About CineMatch AI

Your intelligent movie discovery platform

1. Project Overview

CineMatch AI is a machine learning based movie recommendation system designed to help users discover movies based on their interests. Users can search for a movie and receive recommendations for similar movies.

2. How Does It Work?

The system uses content-based filtering to recommend movies. It analyses movie information such as titles, descriptions, genres, languages and keywords to identify similarities.

  • Users enter a movie title.
  • The system finds the selected movie in the dataset.
  • TF-IDF converts movie information into numerical vectors.
  • Cosine similarity calculates how similar movies are.
  • The system displays the top recommended movies.

3. Machine Learning Algorithms

  • TF-IDF: Converts text information into numerical features.
  • Cosine Similarity: Measures similarity between movie feature vectors.
  • Content-Based Filtering: Recommends movies based on their content.

4. Technologies Used

  • Python
  • Pandas and NumPy
  • Scikit-learn
  • Flask
  • HTML and CSS
  • TMDB API for movie posters and information
  • Matplotlib for data visualization

5. Dataset Information

CineMatch AI uses a movie dataset containing Indian and worldwide movies. The dataset includes movie titles, languages, genres, descriptions, ratings, keywords and release dates.

6. Key Features

  • Movie search functionality
  • AI-based movie recommendations
  • Indian movie recommendations for Indian searches
  • Movie posters and ratings
  • Analytics dashboard with five visualizations
  • Simple and user-friendly interface
